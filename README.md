# RefactorAI

**RefactorAI** is a lightweight AI chatbot built with **React 18**, focused on programming, code analysis, debugging, refactoring, and developer assistance.

<a href="https://fazilmemmedzade.github.io/RefactorAI/">Visit site</a>

## ✨ Features

* 🤖 AI programming assistant
* 💻 Code analysis & explanation
* 🔧 Refactoring & optimization
* 🐞 Debugging assistance
* 🔑 Bring Your Own API Key
* 💬 Conversational chat
* 📝 Markdown & code rendering
* 🎨 Syntax highlighting
* ⚠️ API error handling
* 📱 Responsive UI

## 🛠️ Tech Stack

* **React 18**
* **JavaScript**
* **Axios**
* **React Markdown**
* **Remark GFM**
* **React Syntax Highlighter**
* **React Icons**
* **CSS3**
* **OpenAI-compatible Chat Completions API**
* **Tailwind CSS**

## 📋 Requirements

* Node.js
* npm
* Git
* AI API Key

## 🚀 Installation

### 1. Clone

```bash
git clone https://github.com/fazilmemmedzade/RefactorAI.git
cd RefactorAI
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure API

Create `.env`:

```env
REACT_APP_API_URL=https://api.openai.com/v1/chat/completions
```

### 4. Run

```bash
npm start
```

## 🧠 Main Components

| Component       | Description                             |
| --------------- | --------------------------------------- |
| `Header`        | Application header and API key controls |
| `ChatContainer` | Main chat interface                     |
| `MessageList`   | Conversation messages                   |
| `MessageItem`   | Message and code rendering              |
| `InputArea`     | User message input                      |
| `ApiKeyModal`   | API key setup                           |
| `useChat`       | Chat state and API communication        |
| `openaiService` | AI API requests                         |
